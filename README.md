# Jharkhand Khoj

##  About the Project

Jharkhand Khoj is a tourism-focused web project developed as part of Smart India Hackathon 2025. The project aims to showcase tourist destinations and attractions across Jharkhand through a digital platform.

##  Objective

- Promote tourism in Jharkhand
- Provide information about tourist destinations
- Create an easy-to-use digital tourism platform

##  Technologies

- Web Technologies
- Database
- Deployment: Vercel
